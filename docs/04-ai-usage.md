# 04 AI 使用

本项目实现和文档由 Codex AI 辅助编写。AI 辅助覆盖需求拆解、Python CLI、工具层、决策循环、模型接口、自动化测试、合成数据和交付说明。没有在仓库中写入密钥、真实业务资料或个人数据。

## 提交者参与

提交者选择题目 2，提供 GitHub 仓库地址和本地 API 配置，并要求先提交原项目、忽略凭据文件，再接入 API、测试和推送。提交者还提供了本考核验收规范。代码实现由 AI 辅助完成；本记录不声称提交者独立手写或手动改动了具体代码行。

实现中的关键约束与验证包括：

- AI 生成后依据自动测试结果修正了成本断言和 Trace 检查方式。
- Agent 自行构造待保存草稿并重复校验预算与截止时间，不接受模型直接报告保存成功。
- 保存使用 request ID 与输入指纹做幂等控制；工具故障通过真实执行结果进入下一次决策上下文。
- 离线 Mock 与真实模型接口清楚区分；Mock Trace 不被表述为真实模型效果。
- 用 `unittest` 和实际 CLI 输入输出验证，不以截图替代代码或运行记录。

Codex 在本工作区核验了运行输出、预算与工具失败路径、凭据忽略状态和远端 SHA。验证包括 13 项离线单测、从 `apikey.txt` 加载配置的两次真实模型执行，以及远端 `master` 与最终本地 commit SHA 的一致性检查。评审者可检查 `src/planner.py`、`src/tools.py` 和 `tests/test_planner.py`，并按 README 命令复跑离线测试。
