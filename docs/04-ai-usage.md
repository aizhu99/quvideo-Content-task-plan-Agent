# 04 AI 使用

本项目实现和文档由 Codex AI 辅助编写。AI 辅助覆盖需求拆解、Python CLI、工具层、决策循环、模型接口、自动化测试、合成数据和交付说明。没有在仓库中写入密钥、真实业务资料或个人数据。

实现中的关键约束与验证包括：

- AI 生成后依据自动测试结果修正了成本断言和 Trace 检查方式。
- Agent 自行构造待保存草稿并重复校验预算与截止时间，不接受模型直接报告保存成功。
- 保存使用 request ID 与输入指纹做幂等控制；工具故障通过真实执行结果进入下一次决策上下文。
- 离线 Mock 与真实模型接口清楚区分；Mock Trace 不被表述为真实模型效果。
- 用 `unittest` 和实际 CLI 输入输出验证，不以截图替代代码或运行记录。

评审者应检查 `src/planner.py`、`src/tools.py` 与 `tests/test_planner.py`，并按 README 命令自行复跑。若提交者在本地继续修改，请在此处补充实际修改内容和额外验证，不要把未发生的人工修改写成事实。
